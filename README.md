# Portfolio — Agustin Donalisio

Personal portfolio of Agustin Donalisio, Full Stack Developer based in Buenos Aires, Argentina.

**Live:** https://dazxon.github.io/portfolio/

## Stack

Plain HTML, CSS and a few lines of vanilla JavaScript. No build step, no dependencies.

External resources loaded from CDN:

- Google Fonts (Poppins, Roboto)
- Font Awesome icons

## Structure

```
.
├── index.html              # Single-page site
├── css/styles.css          # All styles
├── images/                 # Profile picture, favicon
└── cv/                     # CV PDF
```

## Running locally

Open `index.html` in a browser. That's it.

## Deployment

Served by GitHub Pages directly from the `main` branch (root). Any push to `main` is published automatically.
